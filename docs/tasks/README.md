# Approved and proposed FedKLS task briefs

Place one small, reviewable brief per meaningful task here, named `TASK-YYYYMMDD-short-description.md`, using [`../TASK_TEMPLATE.md`](../TASK_TEMPLATE.md). The brief is the **input contract** to a new Codex conversation; output evidence belongs under `reports/`, not in the brief itself. Keep dated tasks even if a new window replaces an old one, and update their status with truthful recorded evidence.

Do not create a fake 'currently approved' task. A proposed experiment is not a launch authorization. For the latest known project-level state see [`../PROJECT_STATUS.md`](../PROJECT_STATUS.md), then validate against current Git and the newest signed-off report.
