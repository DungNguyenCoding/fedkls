# Wireless research proposal (preserved original LaTeX)

These `.tex` files are the original mathematical proposal used to plan the
wireless extension, including `wireless_model.tex`, `joint_problem.tex`,
`method1.tex` and `implementation.tex`. They are retained unchanged as
research sources. **Implemented behavior is described in**
[`../../WIRELESS.md`](../../WIRELESS.md); the proposal is not proof that
every idealization was implemented verbatim. The original proposal README
and implementation review are in
[`../../archive/2026-11-12-snapshot/docs/wireless/proposal/`](../../archive/2026-11-12-snapshot/docs/wireless/proposal/).
